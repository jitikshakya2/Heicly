Why AVIF keeps showing up uninvited

You probably didn't choose AVIF. Almost nobody does — it just shows up. Chrome, most CDNs, and a growing number of e-commerce and stock-photo sites have quietly started serving images in AVIF by default, because the format compresses roughly 50% smaller than JPG at a similar visual quality. For a website trying to shave load time, that's a real win. For the person on the receiving end trying to save the picture, edit it, or attach it somewhere, it's a file format their software may never have been built to recognize. That gap — the web moving faster than the tools people actually use to open, edit, and print images — is really the whole story behind "why won't my AVIF open." It isn't broken. It's just early, and everyone downstream of the browser is still catching up at their own pace.

The Windows problem, specifically

This gets worse if you're on Windows, which is probably why "avif won't open windows 10" and "avif won't open windows 11" show up in search bars so often. Out of the box, File Explorer usually renders AVIF files as a plain white icon with no thumbnail at all, and double-clicking one just launches the Photos app straight into an error message. Microsoft does publish an AV1/HEIF extension through the Microsoft Store that fixes previews and basic viewing — but it won't help you inside Outlook, older versions of Office, most desktop print software, or any app that was written before AVIF existed. You end up patching one program at a time instead of just fixing the actual file.

AVIF vs JPG — is one really "better"?

Technically, yes, AVIF is the more advanced format. It compresses harder without losing much visible detail, and it supports things JPG simply never will, like transparency and HDR. But "technically better" and "usable right now" aren't the same claim. JPG has thirty-odd years of near-universal support behind it — every operating system, every editor, every photo kiosk, every inbox. That's really the whole trade-off in one line:
